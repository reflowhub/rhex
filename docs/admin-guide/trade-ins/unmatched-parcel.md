# Log and resolve an unmatched parcel

Sometimes a parcel arrives that doesn't match any trade-in. Maybe there's no note in the box, the customer used their own label, or the details are wrong. Log it so it isn't lost, then work out who it belongs to.

## Log it

1. On **Receive Parcel**, search for the parcel as usual (see [Receive a parcel](receive-parcel.md)).
2. When nothing matches, click **Log unmatched parcel**. If there were matches but none are right, click **None of these — log unmatched parcel**.
3. Fill in what you can:
   - **IMEI**, if you can read it from the device
   - **Photo** of the parcel and its contents
   - **Note**: sender details, what's in the box, any note inside
4. Click **Log Parcel**.

The parcel appears under **Open Unmatched Parcels** at the bottom of the Receive Parcel screen. Keep the device somewhere separate and labelled until it's resolved.

## Resolve it

Try to find the trade-in it belongs to:

- Search **Quotes** for the sender's name or email, or a TI- reference from a note in the box.
- Search **Receive Parcel** again using the IMEI.
- Check whether the trade-in has **expired** or been **cancelled**. Search **Quotes** for the customer's name and look at the status.

Then:

1. If you find the trade-in and it can be received, receive it as normal from the quote page (**Mark Received**).
2. On **Receive Parcel**, click **Resolve** next to the logged parcel.
3. Type what happened, for example "Matched to TI-1042" or "Returned to sender".

Resolved parcels disappear from the list.
