# Clear out fake acceptances

Bots and people testing the site sometimes accept quotes with fake details. Clear these out before you send labels, so you don't pay for labels nobody will use.

## Steps

1. Go to **Trade-in Ops → Awaiting label**.
2. Tick the box on each row that isn't genuine: nonsense names, throwaway emails, obvious test details, or the same details repeated many times.
3. Click **Cancel as not genuine**.
4. Confirm.

The selected trade-ins are cancelled with the reason "Not genuine". The customer isn't emailed. These trade-ins are left out of analytics and sales funnel figures.

**This can't be undone.** If you're not sure about one, open it and check the details first.

## If something goes wrong

- **Some failed.** The message lists which ones and why. Usually another admin already changed that trade-in. Click **Refresh** and check it again.
- **A real customer was cancelled by mistake.** It can't be reopened. Create a new quote and accept it for them (see [Create and accept a quote](create-and-accept.md)). The new quote uses today's price.

To cancel a single trade-in for any other reason, see [Cancel a trade-in](cancel.md).
