# Return a device

Return a device when we won't buy it, or when the customer rejects a revised offer. Returning is two steps: start the return, then confirm the device has been sent back.

## Start the return

A trade-in moves to **Returning** in one of these ways:

- **You start it**, from **Received**, **Inspected** or **On Hold**:
  1. Open the quote and click **Return Device**.
  2. Enter the reason, for example "Not the device described" or "Activation locked, customer can't remove".
  3. Click **Return Device**.
- **The customer rejects a revised offer**, or doesn't answer it in time. This happens automatically (see [Follow up a revised offer](revised-offer.md)).

**No email is sent** when a trade-in moves to Returning. If you started the return, tell the customer why and confirm their return address. The address on the quote is in the Customer Details box.

## Send it back

1. Pack the device and post it with Australia Post tracking to the customer's address.
2. On the quote, click **Mark Returned**. The box shows the address to return it to.
3. Enter the **Return tracking number** (optional, but the customer can only track the parcel if you add it).
4. Click **Mark Returned**.

The trade-in moves to **Returned**, which is the end of the journey. The customer is emailed that their device is on its way back, with the tracking number and a tracking link if you entered one.

Only mark it returned once the parcel has been posted, because the email tells the customer it's on its way.

## Good to know

- You can't return a trade-in that's already **Paid**.
- You can't start a return from **Revised**. The customer rejects the offer, or it expires (see [Follow up a revised offer](revised-offer.md)).
